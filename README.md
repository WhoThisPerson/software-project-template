# Software Project Template

A reusable template for planning and documenting software projects
before and during implementation.

## Usage

1. Create a new repository from this template.
2. Complete the Overview and Requirements sections.
3. Define the system architecture.
4. Define data models and APIs.
5. Identify edge cases and failure scenarios.
6. Define the testing strategy.
7. Document important design decisions.
8. Update the document as the implementation evolves.

## Philosophy

The purpose of the design document is not to predict every
implementation detail.

It is intended to identify requirements, constraints, design
decisions, edge cases, and tradeoffs before implementation.
